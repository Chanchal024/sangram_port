# Nikhil Graphix — Modern Creative Portfolio

A sleek, modern, and high-performance portfolio website built for **Nikhil Barik** (Graphic Designer, Video Editor, and Motion Designer), inspired by high-end dark luxury cyber-neon aesthetics.

## 🚀 Built With

- **[React 19](https://react.dev/)**: Interactive component architecture
- **[Tailwind CSS](https://tailwindcss.com/)**: Glassmorphism, custom violet/purple glow design system
- **[GSAP](https://gsap.com/)**: Entrance timelines, floating badge micro-interactions, and ScrollTrigger
- **[Lenis](https://lenis.darkroom.engineering/)**: Ultra-smooth inertia scrolling
- **[Lucide Icons](https://lucide.dev/)**: Clean modern icon set
- **[Vite](https://vite.dev/)**: Fast modern development server & bundler

---

## ✨ Features

- **Hero Visual Section**: High-impact typography, dual CTAs, ambient neon aura, floating experience/location badges.
- **Marquee Ticker**: Continuous animated strip (`✦ DESIGN • EDIT • CREATE • REPEAT`).
- **Selected Work**: Interactive category filter (`ALL`, `BRANDING`, `SOCIAL MEDIA`, `THUMBNAILS`, `MOTION`) with detail modals.
- **About the Artist**: Biography, value pillars, animated stats, and tool proficiency meters.
- **Specialized Services**: Numbered service cards with breakdowns and interactive inquiry triggers.
- **Interactive Contact**: Floating modal and full-page inquiry form with direct communication channels.
- **Fully Responsive**: Adapts seamlessly to mobile, tablet, and widescreen desktop layouts.

---

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 3. Production Build
```bash
npm run build
```
